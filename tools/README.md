# Optional tools

TidyWin does not bundle NVIDIA Profile Inspector. If you want the optional NVIDIA Gaming Mode step, download its release ZIP from the [upstream project](https://github.com/Orbmu2k/nvidiaProfileInspector/releases/latest) and extract the complete release into:

```text
tools/nvidiaProfileInspector/
```

Keep `nvidiaProfileInspector.exe` directly inside that folder. TidyWin detects it automatically. The downloaded utility and its generated profile exports are ignored by Git and should not be committed to this repository.
